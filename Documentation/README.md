## Report Summary

The report covers:

- **System Architecture** — ESP32 sensing layer, PHP/MySQL backend, dashboard, and optional AI layer
- **Hardware & Wiring** — full component list and GPIO wiring table
- **Status Classification Rule** — the gas/pH threshold logic used across firmware, API, and AI fallback
- **System Operation** — step-by-step data flow from sensor to dashboard
- **Sample Output** — LCD display, API JSON response, and dashboard behavior
- **Results** — end-to-end test cases and outcomes
- **Cost Analysis** — itemized bill of materials with actual invoice pricing (≈ BDT 4,318 total)
- **Industrial & Market Demand** — food waste statistics and target use cases
- **Discussion & Future Work** — limitations and planned improvements
